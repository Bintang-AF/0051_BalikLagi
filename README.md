# BalikLagi

Aplikasi Kartu Loyalitas Digital untuk UMKM berbasis Android.

## Deskripsi
BalikLagi merupakan aplikasi mobile yang dirancang untuk membantu
UMKM mengelola program loyalitas pelanggan secara digital.

Melalui aplikasi ini, pelanggan dapat mengumpulkan stempel
dari transaksi dan menukarkannya dengan reward yang tersedia.

## Tujuan
- Mendigitalisasi kartu loyalitas pelanggan.
- Mempermudah pengelolaan stempel dan reward.
- Membantu UMKM meningkatkan loyalitas pelanggan.

## Teknologi
- Kotlin
- Jetpack Compose
- MVVM
- REST API
- MySQL
